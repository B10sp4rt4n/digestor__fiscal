Digestor Fiscal Docs API

Quickstart

Onboarding técnico en 5 minutos

1) Crear sandbox

curl -X POST "https://api.tu-dominio.com/auth/sandbox/signup" \
  -H "Content-Type: application/json" \
  -d '{"username":"demo_dev"}'

2) Subir primer documento

curl -X POST "https://api.tu-dominio.com/v1/documents" \
  -H "Authorization: Bearer TU_TOKEN" \
  -F "file=@./mi_csf.pdf" \
  -F "document_type=csf"

3) Consultar estado

curl -X GET "https://api.tu-dominio.com/v1/documents/DOCUMENT_ID" \
  -H "Authorization: Bearer TU_TOKEN"
